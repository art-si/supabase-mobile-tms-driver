# 司机端数据库接口

这些脚本以现有 TMS 表、登录身份函数和审核流程为基础。2026-11-16 已以同一事务应用到本仓配置的远端 Supabase，新增五个公开 RPC。公开入口只对已登录用户开放，司机、租户和运单校验在私有实现中执行。过磅记录、在途费用和 AI 助手继续使用原有接口。

| 文件 | 司机权限 | 后续处理 |
| --- | --- | --- |
| [driver-appointments.sql](driver-appointments.sql) | 查看、申请本人运单的提货或送货预约 | 调度确认、安排进场和完成 |
| [driver-exception.sql](driver-exception.sql) | 对符合条件的本人运单提交异常，查询自己提交的报备 | 进入现有运输异常待处理队列。预计运费供复核，不生成财务单据 |
| [driver-certification.sql](driver-certification.sql) | 查看自己的认证总体状态和各证件审核状态 | 证件更新、审核和撤销沿用既有后台权限 |

部署验收应先在测试环境使用司机、其他同租户司机、其他租户账号和未登录请求验证接口授权。确认调度端能看到预约和异常记录并处理其状态，再检查司机端刷新后能看到正确结果。认证需复查既有后台审核读取接口仍遵守原权限，并检查认证通过、证件变更和无需认证三种情况。
